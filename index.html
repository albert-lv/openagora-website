Quick Start

Get your first rollout running in under 5 minutes

Terminal 
# 1. Clone and build
git clone https://github.com/albert-lv/OpenAgora.git
cd OpenAgora
make build

# 2. Start the Arena Server
./bin/openagora-server

# 3. Run your first rollout
cd examples/quickstart
./run.sh
