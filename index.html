🔄 Full-Cycle Coverage

Rollout orchestration, sandbox execution, verification, and structured trajectory storage — every step is covered.

Four Planes

One Pipeline. Four Composable Layers.

Each plane is independently replaceable and production-ready.

🎮 ✅ Available

Rollout Control Plane

LLM proxy with deterministic sampling, token budgets, and trajectory capture. Injects logprobs for all backends and top_logprobs for vLLM/SGLang.

LLM Proxy Sampling Injection Trajectory Capture
📦 ✅ Available

Sandbox Plane

Containerized agent execution with safe, reproducible environments. Docker provider available; mock provider for dev without Docker.

Docker Sandbox Contract Reproducible

Verification Plane

Structured SWE-bench verification + multi-language parsers. Decoupled reward computation independent from agent logic.

Structured, append-only trajectory storage optimized for RL training. PPO, GRPO, DPO ready out of the box.

Quick Start

Get Your First Rollout Running

Five minutes from clone to a verified agent rollout.

Terminal 
# 1. Clone and build
git clone https://github.com/albert-lv/OpenAgora.git
cd OpenAgora
make build

# 2. Start the Arena Server
./bin/openagora-server

# 3. Run your first rollout
cd examples/quickstart
./run.sh
🐳

No Docker? Use ./bin/openagora-server --sandbox=mock for development. The mock provider skips container creation while keeping proxy, trajectory, and verification fully functional.

🧠

LLM Backend: Supports Ollama, vLLM, and SGLang. The proxy auto-injects logprobs for all backends and top_logprobs for vLLM/SGLang.

The Sandbox Contract

Any container that follows these three rules can run in Arena:

1 Read task from /sandbox/.arena/task.json
2 Route LLM calls through OPENAI_BASE_URL injected by Arena
3 Signal completion by writing /sandbox/.arena/done

That's it — language-agnostic and framework-agnostic.
