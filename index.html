Quick Start

Get your first rollout running in under 5 minutes

Terminal 
# 1. Clone and build
git clone https://github.com/albert-lv/OpenAgora.git
cd OpenAgora
make build

# 2. Start the Arena Server
./bin/openagora-server

# 3. Run your first rollout
cd examples/quickstart
./run.sh
🐳

No Docker? Use ./bin/openagora-server --sandbox=mock for development. The mock provider skips container creation while keeping proxy, trajectory, and verification fully functional.

🧠

The Sandbox Contract

Any container that follows these three rules can run in Arena:

1 Read task from /sandbox/.arena/task.json
2 Route LLM calls through OPENAI_BASE_URL injected by Arena
3 Signal completion by writing /sandbox/.arena/done

That's it — language-agnostic and framework-agnostic.

Relationship Chat RL Demo

Watch a small model learn how to talk to your partner without stepping on landmines

Scenario: “你又忘了我们的纪念日”

We turned the classic “how to chat with your girlfriend/wife” problem into a reinforcement-learning task. The model generates a reply; a hidden rubric scores it on empathy and penalizes dismissive phrases like “至于吗” or “冷静一下”. PPO on a CPU-only laptop pushes the verify success rate up over successive iterations.

  • 🧠 Base model: Qwen/Qwen3.5-0.8B + LoRA
  • 🏛️ Infra: Arena rollout / verify / trajectory plane
  • 📈 Dashboard: live verify-success-rate trend
  • 🦙 Deploy: import the LoRA adapter directly into Ollama
Run the demo 
git clone https://github.com/albert-lv/OpenAgora.git
cd OpenAgora/examples/relationship-chat-rl
docker compose up --build

Open http://localhost:9091 and watch the Verify Stats tab.

Code Colosseum Benchmark

Head-to-head agent comparison on 10 classic LeetCode-style problems

Real agents, real problems, real metrics

We ran every agent against 10 problems ranging from easy (Two Sum) to hard (Edit Distance). Each agent receives the same system prompt and a single shot at generating a passing Python solution. Arena's verification plane compiles, runs hidden tests, and returns a reward — feeding both the leaderboard and the GRPO trainer.

  • 🤖 Agents: Claude Code, OpenAI Codex, OpenCode, Kimi Code CLI
  • 🧪 Problems: 10 classic DP / array / string tasks
  • 📊 Metrics: pass@1, reward, tokens, cost, reward/$
